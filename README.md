## 📌 Problem & Impact
Automated Applicant Tracking Systems (ATS) filter out over **75% of early-career technical applicants** before a human engineer or recruiter ever sees their profile. First- and second-year students are disproportionately affected because:
1. They lack years of full-time experience to mask missing target keywords.
2. Their project descriptions rely on passive phrasing (*"worked on"*, *"helped with"*, *"responsible for"*).
3. Bullets lack quantifiable metrics ($\%$, latency, user counts, scale) as prescribed by Google's XYZ formula.

**ResumeScore Pro** equips students with a 100% private, client-side audit engine that simulates enterprise ATS parsers (Workday, Greenhouse, Taleo) and guides them to Google-caliber project bullets.

## 🚀 Standout Features (Competition-Winning Level)

### 1. 🤖 ATS Recruiter Scanner & Parser Simulator (`AtsSimulator.tsx`)
- **Entity Extraction Engine:** Emulates Workday/Greenhouse parsers to extract Candidate Name, Email, Graduation Year, University, and Portfolio links.
- **Automated Knockout Screeners:** Evaluates class year cohort eligibility, minimum keyword match threshold ($\ge 50\%$), and single-column parseability.
- **Raw Lexical Stream Terminal:** Live terminal feed showing raw tokenized output generated by ATS screeners.

### 2. ✍️ Google's XYZ Formula Bullet Studio (`BulletImprover.tsx`)
- **Google XYZ Standard:** Implements Laszlo Bock's universal standard:
  $$\text{Accomplished [X], as measured by [Y], by doing [Z]}$$
- **Interactive 4-Step Builder:** Select power verbs, define core deliverable, quantify measurable outcome, and specify technologies.
- **Batch Resume Bullets Enhancer:** Automatically parses every project bullet in the user's active resume, scores each from $0\text{--}100$, and provides a 1-click shortcut to upgrade it in the formula studio.
- **Before-and-After Technical Library:** Curated examples across Full-Stack, Backend, Machine Learning, Frontend, and DevOps.

### 3. 📊 Keyword Density & Frequency Matrix (`KeywordDensityHeatmap.tsx`)
- Side-by-side dual bar charts comparing keyword occurrences in the Job Description vs Resume.
- Categorizes density into **Optimal (1x–4x)**, **Under-represented**, **Missing**, and **Keyword Stuffing Risk (>6x)**.

### 4. 🔀 Interactive Resume Diff & Version Comparator (`ResumeDiffViewer.tsx`)
- Line-by-line visual diff comparing the student's baseline resume against their updated, ATS-tailored version.
- Visual highlighting of additions (green) and modifications with word count tracking.

### 5. 📄 Harvard / Stanford ATS Printable Document (`AtsResumePreview.tsx`)
- Single-column, ATS-compliant paper document preview formatted to Ivy League career guidelines.
- **Interactive Font Toggle:** Switch between Modern Sans-Serif and Classic Academic Serif.
- **1-Click Print / Save to PDF:** Uses `window.print()` with dedicated clean print stylesheets.

### 6. 🎯 4-Pillar Scoring Model & Confetti Celebration (`ScoreOverview.tsx`)
- **Weighted Score:**
  - 🎯 Target Keyword Match ($40\%$)
  - ⚡ Action Verb Strength ($25\%$)
  - 📈 Quantified Impact / XYZ Formula ($20\%$)
  - ✍️ Single-Column Format & 3rd-Person Style ($15\%$)
- **Readiness Tiers:** *Google / Meta Ready*, *Unicorn Startup Ready*, *Competitive Applicant*, *Needs Targeted Refinement*.
- **Celebration Confetti:** Zero-dependency canvas confetti explosion triggers when students cross $80\%+$.

### 7. 🔍 Weak Action Verb & Passive Voice Detector (`WeakVerbsCard.tsx`)
- Detects 16+ passive phrasing patterns (*"worked on"*, *"helped"*, *"responsible for"*, *"made"*, *"utilized"*).
- Explains recruiter psychology and provides **1-click power verb upgrades** categorized by Engineering, Optimization, Testing, and Leadership.

### 8. 📚 Action Verb Thesaurus (`VerbsThesaurus.tsx`)
- 60+ categorized engineering verbs with 1-click copy.
